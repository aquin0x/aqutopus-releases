İstemciler ve Kurulum Dosyaları

Windows

Windows 10 / 11 (x64)
Electron tabanlı masaüstü düğümü. Görev çubuğunda arka planda çalışır, yerel CLI ve API anahtarlarını yönetir.
Kurulum Paketini İndir (.exe)

macOS

macOS 12+ (Universal)
Apple Silicon (M1/M2/M3/M4) ve Intel Mac'ler için optimize edilmiş masaüstü istemcisi.

Android

Android 9.0+
